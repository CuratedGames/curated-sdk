# Developer admin

The developer admin is where you set up your organization, create applications, build the store
page, upload builds, and release. Sign in with your Curated store account.

## First steps

1. **Create your organization**. You can create one per account.
2. Complete **Know your customer** verification.
3. Sign both partner agreements under **Agreements**. They are required before you can create
   apps.
4. Click **Create a new application**. Each application uses one product credit, bought by
   paying the Application Fee. You can start from scratch or from a **Public Steam store URL**.

## Working on an application

Open an application to reach its [Release Progress](./release-progress) page. From there:

| Stage | What you do | Guide |
| --- | --- | --- |
| Store Presence | Listing copy, media, content survey, pricing | [Basic Info](./store-presence/basic-info) and the pages after it |
| Game Build | Builds, depots, packages, installation, EULA, achievements | [Builds](./game-build/builds) and the pages after it |
| Release | Submit for review, set the date, publish | [Release](./release) |

Work on Store Presence and Game Build in any order, then submit from Release.

Need help? Use **Support** in the admin menu.
