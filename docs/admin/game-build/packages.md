# Packages and product keys

**Game Build > Packages and product keys** manages sales licenses. A package grants access to a
set of depots without changing your uploaded files.

## Packages

Under **Create package** set the **Package id** (cannot change later), **Display name**,
**Distribution** (Store, Regional, Developer review, or Promo bundle), an optional **Region
code**, and the **Included depots**. Click **Create package**. Edit or delete packages from the
list; the standard package cannot be deleted.

## Product keys

Under **Request product keys**, pick the **Package**, a **Quantity**, and an optional **Note for
Curators (optional)**. Click **Request keys**. Curators approve requests before keys are issued.
Issued keys appear in the request list.
