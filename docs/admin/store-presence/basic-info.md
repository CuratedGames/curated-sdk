# Basic Info

**Store Presence > Basic Info** holds the facts shown on your store page. Fields marked `*` are
required before you can publish.

## Import from Steam

If the game is on Steam, use **Import from Steam** first. It copies tags, supported languages,
platforms, system requirements, social links, and other fields that exist on both stores. If the
app is not linked to Steam yet, paste the **Steam store URL** (or the numeric app id). After the
import, a dialog lists the Curated-only fields you still need to fill.

## Sections

- **App Type** and **Game Name**. The name cannot change once the store page is visible.
- **Released earlier on other platforms**: optional **First release date** if the game came out
  elsewhere first. The store marks the Curated date with `(*)` and shows this date on hover.
- **Developers, Publishers, and Franchises**: names shown on the store page.
- **External Links** and **Social Media Links**. URLs must start with `http://` or `https://`.
- **Supported Platforms** with Windows system requirements (**Minimum** and **Recommended**).
- **Supported Languages**: per language, tick **Interface**, **Full Audio**, and
  **Subtitles**.
- **Players**: single-player, multiplayer modes, cross-platform.
- **Supported Features**: only features that are already released.
- **Genres**, with a **Primary Genre** shown in store navigation, and **Tags**.
- **Accessibility**: declare features, or **Open Wizard** for the full list with descriptions.
- **3rd Party DRM** and **Anti-Cheat** disclosures.
- **Legal Lines**: copyright and trademark lines for the store page.
- **Support Contact Info**: at least one of website, email, or phone.

Supported languages here describe the store listing. Which language files players download is
set by [language depots](../game-build/depots#depot-localization).
