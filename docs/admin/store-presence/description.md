# Description

**Store Presence > Description** is the store text, per language.

## Fields

- **Title**
- **Short description**: the store highlight, 200 to 300 characters recommended.
- **About this game**: rich text. Use the visual editor or plain markdown. External links are
  removed when you save.

English is required. Switch language with the language tabs. An empty language falls back to
English on the store.

Click **Save description** to save.

## Import from Steam

**Import from Steam** copies the description from your linked Steam page.

## Localization CSV

To translate in bulk, use **Localization CSV**. Rows are title, short description, and About this
game. Columns are languages. Empty columns mean the language is not localized.

- **Download CSV template** to start fresh.
- **Download current CSV** to edit what is saved.
- **Upload CSV** to apply it.

## Custom media

**Upload custom media** adds images and videos for About this game (5 MB per file). Reference a
file in markdown with `![](filename.jpg)`. For a localized file, add the language name before the
extension, for example `hero_italiano.jpg`. English is used when no language is given.
