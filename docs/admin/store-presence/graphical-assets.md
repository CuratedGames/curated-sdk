# Graphical Assets

**Store Presence > Graphical Assets** holds the store, screenshot, and library art, plus
trailers. Drop images on the page: each one goes to the slot that matches its size. Prefer PNG at
the exact size; JPEG is accepted.

| Slot | Size (px) |
| --- | --- |
| Header Capsule | 920 x 430 |
| Small Capsule | 462 x 174 |
| Main Capsule | 1232 x 706 |
| Vertical Capsule | 748 x 896 |
| Page Background | 1438 x 810 |
| Library Capsule | 600 x 900 |
| Library Hero | 3840 x 1240 |
| Library Logo | 1280 x 720 (PNG) |
| Screenshot | 1920 x 1080 |
| Trailer | MP4 or WebM |

Base art should use game artwork, name, and subtitle only. The tabs split the slots into
**Store assets**, **Screenshot assets**, and **Library assets**.
