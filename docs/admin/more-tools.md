# More tools

Optional tools listed under **More tools** on [Release Progress](./release-progress).

## Cloud Save

Choose which save files sync for players who own the game.

- Tick **Enable Cloud Save for this application**.
- **Save paths and patterns**: one per line, relative to the install folder or a known user
  folder, for example `saves/**/*.sav` or `%AppData%/Game/*`. Up to 64 lines.
- **Max size per player (MiB)**.

Click **Save Cloud Save settings**. The game syncs with the SDK: see
[Cloud Save, friends, presence](/guide/cloud-friends-presence).

## Community hub

Post news and announcements on the game's store hub. Players can start discussion threads on the
same page.

## Trading cards

Define card sets and cards. Players trade them on the store Card Market, not the game Resale
Market.

## Lifetime play time

Play time statistics for the game: averages, medians, and players bucketed by time played.
