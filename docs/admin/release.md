# Release

**Release** is the last stage. It has three steps.

## 1. Request approval

The checklist shows Store Presence, Content survey, Game Build, and Review status. When they are
ready, click **Submit for review**. If changes are requested, fix them and click **Resubmit for
review**. The content survey must be complete first.

## 2. Set the Release date

After Staff approves the store page, set the **Intended release date**. Once the store page is
live, players can see and wishlist the game, but cannot buy it before this date and time.

- The earliest release is two weeks after the store page has been visible as Coming Soon.
- The date must be at least 14 days after today.
- It cannot change for 14 days after the store page is published, nor after release.

**Public date display** chooses how the date appears on the store. A vague format (month or year)
sorts the game toward the end of that period in upcoming lists.

## 3. Publish

Click **Publish store page**. Once published and approved, the title is live and cannot be
unpublished.
